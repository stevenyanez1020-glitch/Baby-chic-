# BabyStyle - Baby Clothing E-commerce Website

## Overview
BabyStyle is a static e-commerce website for baby clothing, featuring a clean product catalog, shopping cart functionality, and smooth navigation. The site is in Spanish and targets parents looking for comfortable, safe baby clothing.

## Project Structure
- `index.html` - Main HTML file with product catalog and navigation
- `styles.css` - All styling and responsive design
- `script1.js` - Shopping cart logic, notifications, and interactive features
- `script.js` - Simple time display utility (unused in main site)

## Technical Stack
- **Frontend**: Pure HTML5, CSS3, and Vanilla JavaScript
- **No build tools required**: Static website served directly
- **Responsive**: Mobile-first design with media queries

## Features
- Product catalog with 4 featured items
- Shopping cart with quantity tracking
- Smooth scroll navigation
- Product categories (newborn, babies, toddlers)
- Instagram social media integration
- Notification system for cart updates
